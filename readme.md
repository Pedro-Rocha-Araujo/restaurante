# Projeto Restaurante 🍔
### O presente projeto trata de um sistema de gestão de pedidos de uma lanchonete, tendo as seguintes funcionalidades:
* Cadastro e login para os funcionários
* Possibilidade de cadastrar, editar e deletar pratos do menu
* Possibilidade de cadastrar pedidos e deixa-los na lista de espera
### Tecnologias utilizadas para desenvolver o sistema:
* ReactJs
* NodeJs
* MongooDb Atlas
### Cacacterísticas do projeto:
* Arquitetura MVC
* Projeto devidamente modularizado com React
* Sistema de Login e cadastro com rotas privadas                            
* Utilização básica de criptografia e token JWT
