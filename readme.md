### O presente projeto trata-se de um sistema para um restaurante, tendo as seguintes funcionalidades:
* Cadastro e login para os funcionários
* Possibilidade de cadastrar, editar e deletar os pratos do menu
* Possibilidade de cadastrar pedidos e deixa-los na lista de espera
### Tecnologias utilizadas para desenvolver o sistema:
* React.js
* Node.js | Express
* MongooDb | Mongoose
### Cacacterísticas do projeto:
* Arquitetura MVC
* Projeto devidamente modularizado com React
* Sistema de Login e cadastro com rotas privadas                            
* Criptografia de senhas
* Validação de usuário com token jwt
