# Projeto Restaurante 🍔

### 📝 Descrição do projeto:
O presente projeto é um sistema de gerenciamento desenvolvido para um restaurante, sendo 100% responsivo e desenvolvido com abordagem mobile-first.

<img width="1920" height="945" alt="projeto-restaurante" src="https://github.com/user-attachments/assets/35556f3b-763d-439a-82ea-2a6969cc2c2d" />

### ⚙️ Funcionalidades do Projeto:
* Cadastro e login para os funcionários
* Possibilidade de cadastrar, editar e deletar os pratos do menu
* Possibilidade de cadastrar pedidos e deixa-los na lista de espera

### 🔧 Tecnologias utilizadas para desenvolver o sistema:
* React.js
* Node.js | Express
* MongooDb | Mongoose
### 📐 Cacacterísticas do projeto:

* Arquitetura MVC
* Projeto devidamente modularizado com React
* Sistema de Login e cadastro com rotas privadas                            
* Criptografia de senhas
* Validação de usuário com token jwt
